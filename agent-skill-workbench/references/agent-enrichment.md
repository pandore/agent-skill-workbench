# Agent Skill Enrichment

Use this route when improving one agent's skill set from real work.

## Inputs

Read only what is needed:

- recent sessions or task transcripts;
- agent instructions and tool docs;
- existing skills;
- recurring reports, scheduled tasks, or repeated user requests;
- known failure reports or review notes.

## Process

1. Identify repeated work, missed routing, fragile manual steps, and recurring mistakes.
2. Decide whether the fix is a new skill, an edit to an existing skill, a script, or documentation outside skills.
3. Draft a proposal before remote writes when the change is behavioral or broad.
4. Make one coherent change at a time.
5. Validate with a no-delivery routing canary when the runtime supports it.

## Output

Record:

- why the skill change is needed;
- what evidence supports it;
- files changed;
- validation result;
- remaining risks or follow-up ideas.
